How I work我的方法

Trust is a product
decision.可信，是一种
产品决策。

01

Start with the failure从失败模式出发

I define what must never be silently wrong before choosing a model or interface.在选择模型或界面之前，先定义什么绝不能悄悄出错。

02

Separate judgment from fact把判断与事实分开

Models handle language and ambiguity; deterministic code owns invariants, numbers and gates.模型处理语言与模糊性；确定性代码负责不变量、数字与门禁。

03

Make evidence visible让证据可见

A result should carry its source, confidence, limits and the path that produced it.结果应携带来源、置信度、局限，以及产生它的完整路径。
