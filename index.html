Hi 👋 — I'm Suzy. 嗨 👋 — 我是 紫薇.

I'm a London-based Game Designer focused on F2P systems, economy and monetisation, with two shipped mobile titles. Alongside that work, I build my own games, tools and prototypes — they're what you can play and read here, built on the same design instincts.

I like systems with pressure in them — resource flows, reward pacing, risk/reward loops, and designer-facing tools that make tuning faster. I also like getting from idea to playable quickly: prototyping solo, end to end, so a design can be felt and tested rather than just written down.

我是一名现居伦敦的游戏设计师，专注 F2P 系统、经济与商业化，已有两款上线手游。除了这些工作，我也自己做游戏、工具和原型——网站展示的就是这部分你能直接玩到、读到的内容，背后是同一套设计能力。

我喜欢有张力的系统——资源流、奖励节奏、风险/回报循环，以及能让调参更快的策划工具。我也喜欢快速把想法做成可玩版本：独立、端到端地做原型，让设计能被亲手感受和验证，而不只是写在文档里。

Robot Karesansui

Solo · R3F · WebGL Zen Sim

A small robot perpetually rakes wave patterns into a dry garden. Battery FSM, day/night cycle, weather tiers, eight fauna species — all shader-drawn, no asset pipeline. 一个小机器人不停在枯山水里耙出波纹。电量状态机、昼夜循环、天气分级、八种生物 — 全 shader 绘制，没有资源管线。

Role角色

Solo — sim engine, shaders, robot FSM, synthesised audio.

独立 — 模拟引擎、shader、机器人状态机、合成音频。

Scope范围

  • Heightfield sand sim (1024×1024) with diffusion + drift; rake teeth etch real grooves that slowly fade
  • Pre-computed Catmull-Rom path aligned to the shader's concentric ripples
  • Battery FSM with two-leg dock approach; day/night cycle (3-min loop); weather state machine with three rain tiers
  • Eight fauna species (dragonfly, gecko, frog, sparrow, beetle, butterfly, fireflies, falling leaves)
  • 1024×1024 heightfield 沙地模拟，含扩散与漂移；耙齿留下真实凹痕并缓慢消退
  • 预计算 Catmull-Rom 路径，与 shader 同心波纹像素对齐
  • 两段式归坞的电量状态机；3 分钟昼夜循环；含三档雨势的天气状态机
  • 八种生物（蜻蜓 / 壁虎 / 青蛙 / 麻雀 / 甲虫 / 蝴蝶 / 萤火虫 / 落叶）

06 · Solo · Live tool独立项目 · 在线工具

Gacha Economy Sim

React · TypeScript · Monte Carlo · Web Worker

A real-time gacha-economy simulator for numerical designers — edit pool weights and pity periods, see P50/P90 pull-cost distributions instantly. No engineer round-trips. 面向数值策划的实时抽卡经济模拟器 — 改池子权重与保底周期，立即看到 P50/P90 抽数成本分布。无需工程师介入。

Role角色

Solo — engine architecture, plugin-rule design, UI, test suite.

独立 — 引擎架构、插件式规则设计、UI、测试。

Scope范围

  • Pure 2-level draw engine with a 4-hook plugin-rule interface (pity, scripted first-draw)
  • Target-driven simulation: 1000 players pull until they hit item X → P50/P75/P90/P99 cost
  • Surfaces that the common spreadsheet drop-rate formula overstates true rates by ~20%
  • Inline-editable weights / % / pity periods; multi-scheme save + JSON / xlsx import
  • 纯函数二级抽卡引擎 + 4-hook 插件式规则接口（保底、首抽脚本）
  • 目标驱动模拟：1000 玩家各自抽到目标为止 → P50/P75/P90/P99 成本分位
  • 揭示常见 Excel 掉率公式比真实概率高估约 20%
  • 权重 / 概率 / 保底周期全部 click-to-edit；多方案保存 + JSON / xlsx 导入

Scale规模

60 tests; engine math validated within ±0.4% of closed-form values over 200k Monte Carlo pulls; 100k-pull batches off-thread in ~500ms.

60 个测试；引擎数学经 20 万次蒙特卡洛验证，与闭式解误差 ±0.4% 内；10 万抽批量在 Worker 中约 500ms 完成。

Stack技术栈

React 19 · TypeScript · Zustand · Zod · Web Worker · ECharts · Vitest
