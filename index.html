02 · Solo · MIT独立项目 · MIT 协议

Robot Karesansui

Solo · R3F · WebGL Zen Sim

A small robot perpetually rakes wave patterns into a dry garden. Battery FSM, day/night cycle, weather tiers, eight fauna species — all shader-drawn, no asset pipeline. 一个小机器人不停在枯山水里耙出波纹。电量状态机、昼夜循环、天气分级、八种生物 — 全 shader 绘制，没有资源管线。

Role角色

Solo — sim engine, shaders, robot FSM, synthesised audio.

独立 — 模拟引擎、shader、机器人状态机、合成音频。

Scope范围

  • Heightfield sand sim (1024×1024) with diffusion + drift; rake teeth etch real grooves that slowly fade
  • Pre-computed Catmull-Rom path aligned to the shader's concentric ripples
  • Battery FSM with two-leg dock approach; day/night cycle (3-min loop); weather state machine with three rain tiers
  • Eight fauna species (dragonfly, gecko, frog, sparrow, beetle, butterfly, fireflies, falling leaves)
  • 1024×1024 heightfield 沙地模拟，含扩散与漂移；耙齿留下真实凹痕并缓慢消退
  • 预计算 Catmull-Rom 路径，与 shader 同心波纹像素对齐
  • 两段式归坞的电量状态机；3 分钟昼夜循环；含三档雨势的天气状态机
  • 八种生物（蜻蜓 / 壁虎 / 青蛙 / 麻雀 / 甲虫 / 蝴蝶 / 萤火虫 / 落叶）

Scale规模

~5k LOC TypeScript · single-page R3F scene · zero asset pipeline (everything in-shader except ambient audio).

约 5k 行 TypeScript · 单页 R3F 场景 · 零资源管线（环境音之外全部 shader 绘制）。

Stack技术栈

Vite · React 18 · TypeScript · Three.js (R3F + drei) · zustand · Web Audio API
