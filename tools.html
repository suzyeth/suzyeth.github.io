Reporting pipeline报表管线

A Python (openpyxl) pipeline that generates a multi-sheet live-ops dashboard: retention cohorts, LTV, payer tiers, level funnels and reactivation, with conditional-format heatmaps.

用 Python（openpyxl）自动生成多 sheet 的运营数据看板：留存分群、LTV、付费分层、关卡漏斗和回流，带条件格式热力图。

Version change ledger版本变更台账

A Python script that compares config tables across releases and writes a change ledger, so every config change can be traced to a version.

Python 脚本对比多个版本的配置表，生成变更台账，让每一处配置改动都能追溯到具体版本。

Docs generated from scripts用脚本生成文档

A full optimisation cycle (diagnosis, issue list with repro steps, governed master list) produced by scripts. To change the content, change the script and rerun; nobody hand-edits the spreadsheets.

一整轮优化的诊断、带复现步骤的问题清单和方案总表都由脚本生成。要改内容就改脚本重跑，不手改表格。

Config schema design配置表结构协作
